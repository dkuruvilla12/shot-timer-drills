How-To Guides

Six things worth knowing about the app, each in under a minute. Screenshots are from the current version.

On this page

01

Run your first drill

Every drill runs the same way, whether it's one of the built-in standards or one you built yourself:

  1. Open a drill and tap Start Drill Now.
  2. Tap Shooter Ready. The beep fires after a random delay, and your Competition Electronics ProTimer BT streams shots in live — no typing times by hand.
  3. When the string ends, your time and every split land on screen automatically.
  4. Count hits with the +/− steppers, or tap Fill Remaining as A when every round landed clean.
No timer on hand? Settings → Timer Setup → Use simulated timer generates realistic strings so you can run the whole flow without hardware — it's forced on automatically in the iOS Simulator.

02

Plan a full Range Day

Line up everything you want to run before you even leave the house:

  1. Home → Plan Range Trip → add whichever drills you're bringing, and who's shooting.
  2. On the range, open the trip and tap Run Full Range Day to move through every drill in order — or tap the play button on any single one to run it out of sequence.
  3. Each finished drill gets a green checkmark, and Resume Range Day always picks up on the next one you haven't shot yet.
Results are tracked against each drill, not against the trip — open any drill from History to see every run of it, trip or no trip.

03

See exactly where you gained or lost time

Every result includes a Shot-by-Shot chart plotting each split against your personal best for that same stage — so instead of one final number, you can see precisely which shot cost you time and which one you actually did faster.

It's on the Results screen right after you finish a string, and again anytime from History.

04

Track your progress, by drill or by trip

The History tab keeps a calendar of every day you've logged a run, a running list of Recent Personal Bests, and a toggle to switch how everything below it is grouped:

  • By Drill (default) — see run count, last run, and best hit factor for each drill you've shot.
  • By Trip — the same runs, grouped by the Range Day they happened on.

Tap into any drill for its full run history and a hit-factor trend chart over time.

05

Find, favorite, and duplicate drills

The Drills tab holds your whole library — the 21+ curated standards and qualifications the app ships with, plus anything you've built or imported.

  • Use the search bar to filter by name or keyword instantly.
  • Swipe right on a drill to favorite it; swipe left to duplicate it as a starting point for a variant.
  • The … menu also has Browse Drill Library to add more curated drills, plus CSV import/export.

06

Jump back in from Home

Home is built to get you shooting in one tap:

  • Quick Start — launch straight into any drill.
  • Plan Range Trip — set up your next Range Day.
  • History card — your most recent run and best hit factor, at a glance.
  • Jump Back In — the drills you've run most recently, one tap from running again.

If a session gets interrupted — a force-quit, a phone call — Home also surfaces a Resume card so you never lose a string in progress.
